## Как читать статусы

README описывает текущую интегрированную версию. В документах модели, AI и функций сохранены датированные отчёты отдельных этапов: фразы о будущей интеграции и старые количества тестов относятся к этим этапам. Текущая публикация и итоговые проверки зафиксированы в начале `deployment.md`; порядок работы с ветками — в `repository.md`.

Скриншоты интерфейса находятся в `docs/ui/`; SVG-обложка README — в `docs/assets/`. Это документационные материалы, приложение не использует их в runtime.
