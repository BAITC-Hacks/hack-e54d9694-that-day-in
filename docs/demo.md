# Демо за 5 минут

[← README](../README.md) · [Открыть приложение](https://akim-five-hours.vercel.app)

Один повторяемый пример показывает путь от синтетических данных до бюджета, Score и объяснения. Все суммы — виртуальные единицы, не тенге.

## Основной сценарий

1. Открыть приложение без активных событий карты. На экране «Карта и решения» выбрать район: камера приблизит его, справа появятся десять показателей «до / после».
2. Нажать значок помощи в шапке → **«Загрузить контрольный пример · 95 ед.»**. Кнопка заменяет текущий локальный план примером; для чистого показа удобно открыть отдельный профиль браузера. Активные события нужно предварительно убрать, иначе их резерв может помешать загрузке примера.
3. В сценарии появятся пять мероприятий:

   | Мера | Район | Стоимость |
   | :--- | :--- | ---: |
   | M7 · Школа + детсад | Нура | 24 |
   | M8 · Поликлиника | Нура | 20 |
   | M10 · Освещение и камеры | Нура | 12 |
   | M12 · Платформа обращений | Весь город | 14 |
   | M5 · Чистое топливо | Сарыарка | 25 |
   | **Всего** | | **95** |

4. Выбрать Нуру и сравнить исходные и итоговые значения в правой панели. Кнопка **«Весь город»** возвращает общий вид карты.
5. Нажать **«Рассчитать сценарий»**. Ожидаемые результаты: исходный Score **52,55768**, итог **56,54307** (в интерфейсе **56,54**), прирост **3,98539**, остаток **5**, критических значений после мер **0**.
6. При доступном OpenAI появляется объяснение сильных сторон, рисков и последствий с численными основаниями. При недоступности AI появляется явное сообщение; численный результат остаётся доступен. Формулировки AI могут отличаться при повторении.

## Дополнительные возможности

| Что показать | Действия и ожидаемый результат |
| :--- | :--- |
| События на карте | Очистить план и убрать прежние события → перетащить «Сильные осадки» на Нуру либо выбрать событие и район кликом. Резерв 10, T1: 55 → 51. Удаление события возвращает бюджет и исходные показатели. До трёх событий; они не входят в AI-отчёт и рейтинг основного плана |
| Рекомендации | «Рекомендации» → «Найти улучшения». Сервер предлагает допустимые замены с расходами и выигрышем Score. Применение меняет план и сбрасывает прежний AI-отчёт. Без AI доступны расчётные варианты с явной отметкой |
| Перераспределение бюджета | Снова загрузить пример → «События» → «Сильные осадки». Резерв 10 делает план стоимостью 95 недопустимым: перерасход 5. Заменить M5 на M4 в Сарыарке и рассчитать: меры 85 + резерв 10, остаток 5. Основной сценарий остаётся отдельным |
| Презентация | «Презентация» → сформировать → пролистать → скачать Markdown. С AI — 9 слайдов, при его недоступности — 6 расчётных/служебных |
| Общий рейтинг | «Сравнение» → указать имя → явно опубликовать. При подключённом Redis результат виден в другом браузере. Участник определяется cookie; бюджеты независимы, сохраняется личный лучший результат |

Рекомендации, отдельный редактор события, презентация и рейтинг находятся на экране **«Аналитика и сравнение»**. Перед повторной загрузкой контрольного примера удалить события карты. Публикация создаёт запись в настоящем рейтинге. Для проверки нескольких участников использовать согласованное тестовое окружение. Сценарий события в стандартный рейтинг не попадает.

## Проверки перед показом

Из актуальной ветки `main`, на Node.js 22:

```sh
npm ci
npm run typecheck
npm run lint
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run start -- --port 3001
```

В другом терминале выполнить HTTP-проверки production-сервера без платных AI-вызовов:

```sh
SMOKE_BASE_URL=http://localhost:3001 node tests/api/live-smoke.mjs
SMOKE_BASE_URL=http://localhost:3001 node tests/api/features-live-smoke.mjs
```

Флаг `--live` включает настоящие AI-вызовы и требует согласованного окружения с ключом. Для общего рейтинга дополнительно нужны Redis и `PARTICIPANT_SECRET`; полный протокол проверки описан в [features.md](features.md). Зафиксированные результаты опубликованной версии — в [deployment.md](deployment.md).

## Если что-то недоступно

- **Нет AI:** показать точный расчёт и объяснить, что текстовое заключение требует доступного внешнего сервиса. Не представлять техническое сообщение как AI-отчёт.
- **Нет рейтинга:** проверить серверные Redis-переменные и доступность хранилища. Интерфейс не подставляет вымышленные команды.
- **Каталог обновился:** перезагрузить страницу, чтобы версии клиента и сервера совпадали.
- **Публичная версия отличается от GitHub:** сравнить опубликованный commit в журнале deployment. Автодеплой пока не подключён.
