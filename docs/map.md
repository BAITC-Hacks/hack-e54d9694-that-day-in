# Географическая игровая карта

Карта использует снимок OpenStreetMap от 23 сентября 2026 года: дороги, контуры зданий, водоёмы, парки центральной части Астаны. Область выгрузки: longitude 71.35–71.515, latitude 51.09–51.205. Это ограниченный фрагмент города, а не полный навигационный сервис.

География превращена в SVG: основания зданий взяты из OSM, стены и высоты художественно упрощены, вертикальная координата сжата для полуперспективного вида. Ландмарки нарисованы отдельно, увеличены для узнаваемости и привязаны к центрам соответствующих OSM-объектов. Зум и перемещение выполняются через SVG viewBox; тайлы и ключ картографического сервиса не нужны. На приближении появляются выбранные объекты инфраструктуры из OSM. Набор не является полным или гарантированно актуальным справочником.

## Игровые зоны

Пять цветных зон соответствуют **пяти ID исходного датасета**. Их контуры приблизительные, нарисованы вручную для взаимодействия и не являются официальными административными границами. В современной Астане шесть районов; шестой район не добавляется в расчёт без новой версии датасета. Источники: [официальный перечень районов](https://www.gov.kz/memleket/entities/astana-saulet/press/news/details/1274528), [описание границы Нуры](https://www.gov.kz/memleket/entities/astana-nura/press/news/details/560659?lang=ru).

Разметка содержится в src/features/map/geography.ts и не участвует в вычислении Score. Иконки принятых решений прикреплены к маркеру игровой зоны, а не к конкретному адресу строительства. Городское решение отображается во всех пяти зонах. Режим «До решений» скрывает изменения; «Прогноз» показывает их и изменение индекса района. На карте постоянно видна подпись об условности границ и мест мероприятий.

- public/maps/astana-source.json — OSM-derived компактный набор геометрии / ODbL 1.0.

## Воспроизведение

Для обычного запуска ничего выгружать не нужно: карта включена в Git. Пересборка SVG из сохранённого источника требует только Python 3:

```sh
python3 scripts/build-city-map.py
```

Первичная выгрузка получена через https://overpass-api.de/api/interpreter. Запрос ниже отправляется как form-параметр `data`; результат сохраняется в файл. Не выполняйте его при каждом запуске приложения.

```text
[out:json][timeout:45];
(
  way[highway~"^(primary|secondary|tertiary|residential|trunk)(_link)?$"](51.09,71.35,51.205,71.515);
  way[natural=water](51.09,71.35,51.205,71.515);
  way[waterway=river](51.09,71.35,51.205,71.515);
  way[leisure=park](51.09,71.35,51.205,71.515);
  way[building](51.09,71.35,51.205,71.515);
);
out geom;
```

Преобразование новой выгрузки: `python3 scripts/build-city-map.py /path/to/overpass.json`. При обновлении снимка нужно также пересмотреть координаты ориентиров, инфраструктуру и дату в скрипте. Повторная генерация из закоммиченного компактного источника даёт тот же SVG.
