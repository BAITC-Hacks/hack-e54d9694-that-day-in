# Стилизованная карта Астаны

Карта намеренно упрощена: география Есиля, крупных водоёмов, парков и выбранных главных дорог сохранена из OpenStreetMap, а кварталы показаны 60 условными объёмными зданиями. Геометрия зданий не является контуром реальной недвижимости. Достопримечательности увеличены для узнаваемости и привязаны к координатам исходных объектов. Это визуальное сопровождение сценария, не навигатор или полный справочник инфраструктуры.

Снимок OSM: 23 сентября 2026 года. Область: longitude 71.35–71.515, latitude 51.09–51.205, центральная часть города. Подробная исходная выгрузка сохранена для воспроизведения, но не загружается как фон карты. `public/maps/astana.svg`: 105 963 байта вместо прежних 3 895 427.

## Условные зоны

Пять зон соответствуют ID исходного датасета, а не текущим официальным административным границам. В современной Астане шесть районов. Границы и кварталы иллюстративны, что указано на карте и в методике. Шестой район не добавляется в Score без новой версии датасета. Источники: [официальный перечень](https://www.gov.kz/memleket/entities/astana-saulet/press/news/details/1274528), [описание Нуры](https://www.gov.kz/memleket/entities/astana-nura/press/news/details/560659?lang=ru).

`src/features/map/geography.ts` не участвует в расчётах. Маркеры мероприятий привязаны к зоне, а не к точному адресу строительства; городское мероприятие отображается во всех пяти зонах. «До решений» скрывает изменения, «После решений» показывает дельты индексов и маркеры. На приближении отображается небольшой выбор инфраструктуры из OSM, не полный справочник.

## Управление

Кнопки изменения масштаба и сброса. Перемещение только при удержании кнопки мыши или касании с перетаскиванием. На pointerup/pointercancel/lostpointercapture жест завершается; для мыши дополнительно проверяется `buttons`. Клик после drag подавляется отдельно от состояния жеста. Районы доступны с клавиатуры через Enter/Space и через список под картой. Браузерный тест проверяет движение после отпускания, отпускание за пределами карты и возврат указателя.

## Лицензия и воспроизведение

© OpenStreetMap contributors. Исходная и производная география: [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). [Атрибуция](https://www.openstreetmap.org/copyright) постоянно доступна на карте.

- `public/maps/astana-source.json` — компактная исходная геометрия / ODbL.
- `src/features/map/infrastructure.json` — выбранные объекты инфраструктуры / ODbL.
- `public/maps/astana.svg` — упрощённая визуализация с условными кварталами.

Для обычного запуска сетевой картографический сервис не нужен. Пересборка фона из сохранённого источника:

```sh
python3 scripts/build-city-map.py
```

Python 3, без дополнительных пакетов. Алгоритм упрощает контуры, оставляет выбранные именованные магистрали и крупные водоёмы/парки, рисует условные кварталы в фиксированных местах. Результат детерминирован.

Первичная выгрузка через `https://overpass-api.de/api/interpreter` (form-параметр `data`):

```text
[out:json][timeout:45];
(
  way[highway~"^(primary|secondary|tertiary|residential|trunk)(_link)?$"](51.09,71.35,51.205,71.515);
  way[natural=water](51.09,71.35,51.205,71.515);
  way[waterway=river](51.09,71.35,51.205,71.515);
  way[leisure=park](51.09,71.35,51.205,71.515);
  way[building](51.09,71.35,51.205,71.515);
);
out geom;
```

Проекция в сохранённом файле: `x=(lon-71.35)*6900+20`, `y=(51.205-lat)*6350+20`; даты и координаты нужно пересматривать при обновлении снимка.
