# Публикация хакатонной версии

Ветка `codex/deploy` объединяет `codex/scenario-features` и интерфейс
`codex/ui` (8e3afd4). `main` не изменяется: интеграцией по-прежнему управляет
первый разработчик. Ветка публикации нужна, пока основной merge не готов.

Платформа: Vercel, framework Next.js, Node.js 22.x (из package.json),
установка `npm ci`, сборка `npm run build`.
`.vercelignore` исключает локальные секреты и артефакты из загрузки исходников.

Переменные окружения сервера:

- `OPENAI_API_KEY` — существующий ключ, не передавать в браузер или Git;
- `OPENAI_MODEL=gpt-5.4-mini-2026-03-17`;
- `PARTICIPANT_SECRET` — случайный секрет не короче 32 символов;
- `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` — общее хранилище рейтинга.

Не скачивать настройки хостинга поверх существующего `.env.local`.
После настройки переменных нужен новый deployment.
Без Redis обычная симуляция и AI могут работать, но `/api/leaderboard` возвращает 503.
Новые вкладки дополнительных функций пока не подключены в интерфейсе: их API
готовы, правила интеграции находятся в [features.md](features.md).

До выбора автоматической production-ветки не привязывать публикацию к текущему
`main`: в нём пока только датасет. Первый разработчик может позже переключить
отслеживание на объединённый main. Сам push в произвольную ветку не гарантирует
обновления production-сайта.

Проверки после деплоя: открыть главную страницу и `/api/catalog`, отправить
контрольный сценарий в `/api/simulate` (95 / 56.54307 / 0), выполнить настоящее
`/api/analyze`, проверить подключение рейтинга и публикации двух браузеров.
Рейтинг хранит личные рекорды браузерных участников, а не подтверждённые аккаунты.

Состояние: локальная интегрированная сборка, 128 unit/API-тестов и 6 браузерных тестов прошли.
Публичный адрес и статус подключения сервисов фиксируются после успешного деплоя.
